# AIOS 专业领域情报监测专报

用于发布 AIOS 连续监测专报，并通过固定入口查看最新一期与历史报告。

## 站点结构

- `index.html`：固定入口与历史专报归档
- `reports/2026-09-20.html`：2026-09-20 基线期
- `reports/2026-09-26.html`：2026-09-26 连续研判期

## GitHub Pages

固定入口预期为：

https://zomer2001.github.io/daily-report/

首次启用时，在仓库 **Settings → Pages** 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

保存后即可通过固定入口访问。以后新增专报无需修改二维码。
